## Task C

Task C uses full, unmodified source images. These files are intentionally
excluded from the public source repository and may not be redistributed from
it. They may appear in an official hosted build produced by the project authors
under separate permission. A source build includes Task C only when every
required, separately authorized file is present locally under
`web/public/preset-images/C/`.

The dataset used to train the released GapFill model contains copyrighted image
materials used with permission. It is not distributed because that permission
does not include redistribution of the dataset. Users of the ML pipeline must
provide their own appropriately licensed data.
